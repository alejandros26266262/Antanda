Se reproduce en el navegador; el archivo no se sube a GitHub ni se conserva al recargar.
El enlace se abrirá aparte. No permite reproducir ni sincronizar automáticamente su audio.
Ejemplo: 12.5|Y entonces llegaste **tú**. Las palabras entre **asteriscos** reciben un latido especial. Escribe frases propias o letras que tengas autorización para usar.
Los efectos responden al audio cuando se reproduce un archivo local. Para compartir la música y los cambios entre los dos necesitaremos un almacenamiento y acceso privados; GitHub Pages por sí solo no sincroniza datos.
